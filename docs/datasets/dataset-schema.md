# Mars Mission Dataset Schema Specifications

This document specifies the schemas for the 4 dataset families generated by the Objective 10 Dataset Factory.

---

## 1. Dataset Families

### A. Supervised Learning Dataset
- **Features**: Battery, rover health, position, velocity, terrain, weather, communication state, DTN queue depth, risk score.
- **Labels**: `next_action`, `predicted_failure`, `recommended_replan`.

### B. Time-Series Dataset
- **Sequential Trajectory**: Sequential timestep records stored in Apache Parquet format.

### C. Reinforcement Learning Dataset
- **Gymnasium/SB3 Format**: Tuples `(observation, action, next_observation, reward, terminated, truncated)`.

### D. Anomaly Dataset
- **Fault Ground Truth**: Contains ground-truth fault flags, fault types, start times, durations, and severity levels.
