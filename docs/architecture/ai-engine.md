# Python AI Mission Intelligence & Learning Service Architecture

This document describes the design and service boundary for the Python-based AI Mission Intelligence & Learning Service.

---

## 1. Overview & Service Boundary

The **Python AI Service** (`services/ai-engine`) provides real-time anomaly detection, risk assessment, trajectory prediction, advisory mission recommendations (Objective 7), and mission memory experience learning (Objective 8) for the Earth–Mars Autonomous Simulator.

## 2. Advisory Safety Guarantee

1. **Advisory Authority**: The Python service only produces **recommendations** (`CONTINUE_PLAN`, `REPLAN`, `RETURN_TO_BASE`, `WAIT`, `PAUSE_MISSION`, `SCAN_TERRAIN`, `REQUEST_EARTH_GUIDANCE`, adaptive strategy rankings). It cannot mutate Node.js simulation objects directly.
2. **Safety Validator Gatekeeping**: Every action generated by the Objective 6 Planner as a result of an AI recommendation **MUST** pass through Objective 5 `SafetyValidator` before execution.
3. **Physical Delay Engine**: Physical communication delay calculations rely 100% on Objective 1 `@earth-mars/communication-protocol` speed-of-light metrics ($c = 299,792,458\text{ m/s}$).

## 3. Service API Endpoints

- **`POST /analyze`**: Accepts `AutonomyObservation` JSON payload, returns `MissionIntelligenceReport`.
- **`POST /learn/experience`**: Records `MissionExperience` in memory repository.
- **`POST /learn/analyze`**: Accepts `LearningAnalysisRequest`, returns `LearningAnalysisResponse`.
- **`GET /learn/strategies`**: Returns strategy performance metrics list.
- **`GET /learn/failures`**: Returns detected failure patterns.
- **`GET /learn/statistics`**: Returns memory store statistics.
- **`GET /learn/health`**: Returns learning engine status.
- **`GET /health`**: Health check endpoint.
- **`GET /version`**: Returns service version.
